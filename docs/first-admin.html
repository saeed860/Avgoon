راه‌اندازی اولین مدیر

این صفحه فقط برای فعال‌سازی اولین حساب مدیر است و پس از ایجاد مدیر، سرویس به‌صورت خودکار برای همیشه بسته می‌شود.

پیش‌نیاز: ابتدا کلید RESEND_API_KEY را در بخش Secrets سرویس Worker ثبت کنید؛ سپس در فروشگاه با ایمیل ثبت‌نام کرده و کد یک‌بارمصرف را تأیید کنید. پیامک هنوز فعال نیست. کلید راه‌اندازی مدیر را فقط در پنل Secrets سرویس API نگه دارید و هرگز در GitHub یا سایت عمومی قرار ندهید.

نشانی API باید در تنظیمات میزبانی فرانت‌اند با متغیر AVGOON_API_URL تعیین شده باشد.
