راه‌اندازی اولین مدیر

این صفحه فقط برای فعال‌سازی اولین حساب مدیر است و پس از ایجاد مدیر، سرویس به‌صورت خودکار برای همیشه بسته می‌شود.

پیش‌نیاز: حساب کاربری باید قبلاً در فروشگاه ثبت‌نام کرده و ایمیل یا شماره موبایل آن را با کد یک‌بارمصرف تأیید کرده باشد. کلید راه‌اندازی را فقط در پنل متغیرهای محیطی سرویس API تنظیم کنید؛ آن را در GitHub یا سایت عمومی قرار ندهید.

نشانی API باید در تنظیمات میزبانی فرانت‌اند با متغیر AVGOON_API_URL تعیین شده باشد.
