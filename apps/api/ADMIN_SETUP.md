# راه‌اندازی اولین مدیر آوگون بدون خط فرمان

## تنظیمات یک‌باره در پنل میزبانی API
در قسمت Environment Variables سرویس API این متغیرها را اضافه کنید:

- `ADMIN_BOOTSTRAP_TOKEN`: یک مقدار تصادفی محرمانه با حداقل ۳۲ کاراکتر. آن را در GitHub، کد سایت یا پیام عمومی قرار ندهید.
- `JWT_SECRET`: کلید تصادفی محرمانه با حداقل ۳۲ کاراکتر.
- `WEB_ORIGIN`: آدرس دقیق سایت فرانت‌اند، مانند `https://saeed860.github.io` (بدون مسیر).
- `AVGOON_API_URL`: آدرس HTTPS سرویس API که باید هنگام انتشار در صفحه راه‌اندازی و فروشگاه در دسترس باشد.

همچنین PostgreSQL و `DATABASE_URL` و سرویس ارسال OTP (SMS یا SMTP) باید از قبل در همان پنل میزبانی پیکربندی شده باشند. پس از تغییر متغیرها، سرویس API را از پنل Restart کنید.

## پیش‌نیاز حساب مدیر
حساب موردنظر باید از صفحه عادی فروشگاه ثبت‌نام کرده و ایمیل یا شماره موبایلش را با OTP تأیید کرده باشد. سرویس OTP باید واقعاً به ارائه‌دهنده پیامک یا ایمیل متصل باشد.

## فعال‌سازی از طریق مرورگر
پس از انتشار نسخه جدید سایت، این صفحه را باز کنید:

`https://YOUR-SITE/first-admin.html`

روش شناسایی، ایمیل/شماره تأییدشده و `ADMIN_BOOTSTRAP_TOKEN` را وارد کنید. کلید فقط از مرورگر به API ارسال می‌شود و در پاسخ یا لاگ برنامه بازگردانده نمی‌شود.

این endpoint:
- فقط وقتی فعال است که کلید سرور حداقل ۳۲ کاراکتر و صحیح باشد؛
- در هر ساعت حداکثر ۵ تلاش می‌پذیرد؛
- فقط یک حساب موجود را که از مسیر OTP ایجاد شده به مدیر تبدیل می‌کند؛
- در تراکنش Serializable بررسی می‌کند که هیچ مدیر دیگری وجود نداشته باشد؛
- بعد از ایجاد اولین مدیر، تمام تلاش‌های بعدی را رد می‌کند.

## ورود به پنل مدیریت
پس از پیام موفقیت، به فروشگاه برگردید، از حساب خارج شوید و دوباره با OTP وارد شوید تا نشست جدید با نقش ADMIN دریافت کنید. سپس پنل در مسیر زیر در دسترس است:

`/admin.html`

## نکات انتشار
- آدرس `WEB_ORIGIN` باید با origin واقعی فرانت‌اند دقیقاً یکسان باشد.
- فرانت‌اند باید با `AVGOON_API_URL` به API عمومی HTTPS متصل شود؛ مقدار پیش‌فرض محلی `http://localhost:4000` برای سایت منتشرشده مناسب نیست.
- workflow گیت‌هاب فقط TypeScript build و تولید Prisma Client را بررسی می‌کند؛ جای تست یکپارچه دیتابیس و تست OTP واقعی را نمی‌گیرد.
- فایل `bootstrap-admin.ts` و دستور قدیمی CLI صرفاً مسیر جایگزین عملیاتی‌اند؛ برای این روش نیازی به ترمینال کاربر نیست.
